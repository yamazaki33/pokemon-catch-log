# 🎯 ポケモン捕獲ログ

ポケモンGOの捕獲記録を管理し、場所ごとの湧き効率（1時間あたりの捕獲数）をグラフで可視化するWebアプリケーションです。

コミュニティデイや通常プレイでの効率を記録・分析できます！

## ✨ 機能

### 📝 ログ入力
- 場所、ポケモン名、時間帯、捕獲数を記録
- 自動で1時間あたりの捕獲効率を計算
- メモ欄でイベント情報や天候も記録可能

### 📊 湧き効率グラフ
- **場所別効率グラフ**: どこが一番効率的かひと目で分かる
- **ポケモン別効率グラフ**: ポケモンごとの捕まりやすさを比較
- **時系列グラフ**: 最新20件の推移を確認
- **円グラフ**: 場所別の総捕獲数の割合
- **統計カード**: 総捕獲数、総時間、平均効率などを表示

## 🚀 使い方

### ローカルで実行
1. このリポジトリをクローン
2. `index.html` をブラウザで開く

### GitHub Pagesで公開
1. GitHubにプッシュ
2. Settings → Pages → Source を `main` ブランチに設定
3. 公開されたURLにアクセス

## 💡 技術スタック

- **HTML/CSS/JavaScript**: シンプルな構成
- **Chart.js 4.4.0**: グラフ描画ライブラリ
- **localStorage**: ブラウザにデータを保存（サーバー不要）
- **GitHub Pages対応**: 静的サイトとして公開可能

## 📱 対応ブラウザ

- Chrome / Edge / Safari / Firefox（最新版）
- モバイルブラウザ対応

## 🔒 プライバシー

すべてのデータはブラウザのlocalStorageに保存されます。外部サーバーには一切送信されません。

## 📝 使用例

### コミュニティデイの記録
- 場所: 「公園A」
- ポケモン: 「ミニリュウ」
- 時間: 11:00〜14:00（3時間）
- 捕獲数: 180匹
- → **効率: 60匹/時間**

### 通常プレイの記録
- 場所: 「駅前」
- ポケモン: 「ポッポ」
- 時間: 18:00〜19:00（1時間）
- 捕獲数: 12匹
- → **効率: 12匹/時間**
